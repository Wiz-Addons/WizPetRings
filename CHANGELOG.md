# Changelog

## 1.0.0 — 2026-10-13

Initial public release prepared by wizdevproj.

- Added independent pet command and pet care rings for Hunters in WoW Forever.
- Added held-key flick/release selection and centre cancellation.
- Added direct pet-bar actions for stances and Move To.
- Added direct spell-ID casting for family summon spells such as Call Bear.
- Added a parchment settings window with separate sidebar pages for both rings.
- Added per-character keys, sizes, action layouts, and optional Call Pet spell override.
- Added a dedicated WizPetRings category in the game's binding menu.
- Prevented ring creation and addon key overrides on non-Hunter characters.
- Preserved per-character settings from earlier builds.
